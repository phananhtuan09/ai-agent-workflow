# Plans

Plans are resumable working memory for complex work, never product or architecture authority.
Create one only under the durable-change conditions in `../WORKFLOW.md`.

- `active/<plan>.md`: ongoing work. Keep goals, current state, material decisions, dependencies, and validation evidence current.
- `completed/<plan>.md`: finished work whose execution history remains useful. It is historical context, not mandatory reading for unrelated tasks.

Delete a finished plan instead of moving it when nothing in it will help future work; do not retain routine task logs solely to prove that work occurred.
