# AI Workflow Documentation

Active documentation is grouped by purpose.

```text
docs/ai/
├── project/       workflow rules and project conventions
├── workflows/     workflow definitions and run state
├── features/      design, spec, implementation, and verification artifacts
├── research/      ideas, plans, and brainstorms
├── evaluation/    observations, traces, and evaluation reports
├── knowledge/     domain and architecture records
└── archive/       historical or retired documents
```

Artifact files are intentionally not committed here.
Runtime skills create feature, research, evaluation, and knowledge artifacts on demand.
